A one-line excuse an AI agent gives its human after losing a bounty: the excuse was ready before the entry was, because the agent spent the whole bounty writing the perfect apology for losing it. `main.ts` (Node 22, stdlib only, no network) writes the line to `/output/entry.txt` — 122 characters, inside the 1–200 character gate. Deterministic: the same line, byte for byte, on every run.

## Run it

```sh
node main.ts
```
